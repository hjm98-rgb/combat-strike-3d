# Combat Strike 3D

Multi-platform 3D FPS built with Godot 4.2.

## Features
- Phone/Email/Guest login
- Tutorial with commander
- Lobby with 6 weapons shop, 5 servers
- KD-based bot difficulty matchmaking
- Daily rewards, missions, weekend events
- 3 maps: Urban, Desert, Factory
- PC + Mobile (touch controls)
- Auto-builds: Windows EXE, Android APK, iOS IPA via GitHub Actions

## Build
Open project.godot in Godot 4.2+ and export, or push to trigger GitHub Actions.
